# GenWeb.ai

AI-powered website builder that generates modern, responsive, production-ready websites using pure HTML, CSS, and JavaScript.

---

# ✨ Features

- 🚀 AI Website Generation
- 🎨 Premium Modern UI
- 📱 Fully Responsive Layouts
- ⚡ Real-Time Live Preview
- 🧠 AI Website Editing & Updates
- 🖥 Monaco Code Editor
- ☁️ Website Deployment System
- 🔗 Public Shareable Website URLs
- 💳 Stripe Payment Integration
- 🪙 Credit-Based System
- 🔐 Authentication & Protected Routes
- 📂 Personal Website Dashboard

---

# ⚙️ Environment Variables

## Backend `.env`

Create a `.env` file inside the `server` folder:

```env
PORT=8000

MONGO_URI=your_mongodb_uri

JWT_SECRET=your_jwt_secret

FRONTEND_URL=http://localhost:5173

OPENROUTER_API_KEY=your_openrouter_api_key

STRIPE_SECRET_KEY=your_stripe_secret_key
```

---

## Frontend `.env`

Create a `.env` file inside the `client` folder:

```env
VITE_SERVER_URL=http://localhost:8000
```

# 📦 Installation

## Clone Repository

```bash
git clone https://github.com/yourusername/genweb-ai.git
```

---

## Install Frontend

```bash
cd client
npm install
npm run dev
```

---

## Install Backend

```bash
cd server
npm install
npm run dev
```
